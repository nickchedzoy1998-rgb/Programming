
### Lengths

Write a function named `lengths(lists: list)` which takes a list containing lists of integers as its argument and returns a new list containing the lengths of the lists within the argument list.

- Use a list comprehension.
- The function must be no longer than two lines of code, including the `def` line.

The function should work as follows:

```python
lists = [[1,2,3,4,5], [324, -1, 31, 7], []]
print(lengths(lists))
```

Sample output:

```
[5, 4, 0]
```
