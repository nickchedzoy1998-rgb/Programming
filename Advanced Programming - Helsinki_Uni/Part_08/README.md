# Part 08: Object-Oriented Programming

This section contains my solutions for Part 08 of the University of Helsinki Python Programming MOOC. The exercises focus on the foundations of object-oriented programming in Python: defining classes, creating objects, storing state, writing methods, and building small programs from reusable components.

Each exercise folder contains:

- `exercise.md`: the original exercise description, formatted as Markdown
- `solution.py`: my Python solution

## Topics Covered

- Creating classes and objects
- Defining constructors with `__init__`
- Working with instance attributes
- Writing instance methods
- Returning and comparing object data
- Formatting objects for readable output
- Splitting behaviour across multiple small classes
- Modelling real-world concepts with Python objects
