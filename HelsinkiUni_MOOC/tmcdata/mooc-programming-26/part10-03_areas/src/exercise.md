# Areas

The exercise template contains a class definition for a `Rectangle`. It
represents a rectangle shape. A `Rectangle` works like this:

```python
rectangle = Rectangle(2, 3)
print(rectangle)
print("area:", rectangle.area())
```

## Sample output

```text
rectangle 2x3
area: 6
```

## Square

Define a class named `Square` which inherits from the `Rectangle` class. The
sides of a square are all of equal length, which makes the square a special
case of the rectangle. The new class should not contain any new attributes.

A `Square` object is used as follows:

```python
square = Square(4)
print(square)
print("area:", square.area())
```

## Sample output

```text
square 4x4
area: 16
```
