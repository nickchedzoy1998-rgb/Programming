# Laptop Computer

The exercise template contains a class definition for a `Computer`, which has
the attributes `model` and `speed`.

Define a class named `LaptopComputer` which inherits from the class `Computer`.
The constructor of the new class should take a third argument, `weight`, of
type integer.

Also include a `__str__` method in your class definition. See the example below
for the expected format of the string representation printed out.

## Example

```python
laptop = LaptopComputer("NoteBook Pro15", 1500, 2)
print(laptop)
```

## Sample output

```text
NoteBook Pro15, 1500 MHz, 2 kg
```
