# LeetCode Solutions

A structured collection of algorithm and data structure problems solved in Python, focused on building proficiency in computational thinking and code efficiency.

## Structure

- `Tier 1/`: beginner-level problems focusing on arrays, strings, and simple algorithmic patterns.
- `Tier 2/`: intermediate-level problems that introduce graph traversal, tree algorithms, and more complex challenge types.

## Highlights

- `Tier 1/1 - two_sum/two_sum.ipynb`
  - A classic introductory algorithm challenge with step-by-step notebook submissions.
- `Tier 1/13 - roman_to_integer/`
  - Demonstrates string parsing and mapping logic.
- `Tier 1/20 - Valid Parenthesis/`
  - Covers stack-based validation and input correctness.
- `Tier 2/934 - Shortest Bridge/`
  - A stronger algorithm problem involving breadth-first search and connected components.
