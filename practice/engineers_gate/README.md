## Practice protocol

1. Attempt each unseen exercise independently before receiving teaching or hints.
2. State assumptions, output grain/data shape, and a proposed approach before coding.
3. Work in plain `.py` and `.sql` files rather than Jupyter notebooks.
4. Test ordinary cases, edge cases, and erroneous input. Explain time/space complexity where relevant.
5. Afterwards, review mistakes and retry the weak concept on a different example.
6. Avoid storing interview questions obtained in confidence or proprietary company data.
