# Python algorithms — Session 01

## Exercise: Longest substring with distinct characters

**Goal:** Implement a Python function that returns the length of the longest **contiguous** substring containing no repeated characters.

A substring is a continuous section of the original string. Character comparisons are case-sensitive.

### Function contract

`longest_unique_substring(text: str) -> int`

Examples:

| Input | Expected result |
| --- | ---: |
| `"abcabcbb"` | `3` |
| `"bbbbb"` | `1` |
| `"pwwkew"` | `3` |
| `""` | `0` |

## How to work
